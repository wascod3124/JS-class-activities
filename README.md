# JavaScript Class Activities

JavaScript Class Activities repository!

This repository contains practical exercises, class activities, examples, and assignments covered during our JavaScript lessons. It helps students review what they learn in class, practise coding, and improve their programming skills.

## Topics Covered

- **JavaScript:**
- Variables,
-  data types,
-  operators,
- conditional statement

*More topics will be added as we progress through the course.*

## 📁 Repository Structure

```text
JS-class-activities/
├── JavaScript/
├── Class-Assignments/
└── README.md
```

## How to Use This Repository

1. Open the folder for the topic you want to study.
2. Open the activity files to review the code.
3. Download the repository using the **Code → Download ZIP** option on GitHub if you want to practise offline.
4. Open the downloaded files in Visual Studio Code and practise the examples.
5. Try to understand the code and experiment with your own solutions.

## Learning Objectives

- Practise writing and reading code.
- Develop problem-solving skills through practical exercises.
- Build confidence in creating web pages and interactive applications.


Happy coding!
